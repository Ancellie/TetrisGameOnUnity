## Game Description
A classic Tetris implementation where you can:

- Move pieces left and right
- Rotate pieces
- Speed up piece falling
- Restart the game

## How to run Project:

1. Clone repository:
```bash
git clone https://github.com/Ancellie/TetrisGameOnUnity.git
```

2. Open Unity Hub → Add → select cloned project folder

3. Install correct Unity version if needed (check project settings)

4. Open project → wait for import → open main scene → press Play

That's it! Let me know if you need help with any step.
